已选择：—　（我会把该风格实现到修复直播源窗口）
一、现状分析（基于代码事实）
代码事实

当前窗口构成

  • 固定 480×320 对话框，绝对像素布局（SX/SY 缩放）。
  • 标题「修复直播源地址」；暗色标题栏（SetFormDarkModeTitleBar）。
  • 字段：原始地址(只读)、新 IP/域名、新端口、新地址预览(RichTextBox 语法高亮)。
  • 颜色全部由 theme 派生（accent / surface），自动适配明暗主题。
  • 按钮：取消(描边) + 确定替换(实心强调)，主按钮在右侧。
  • 逻辑：输入实时拼接预览；输入 "ip:port" 自动拆分；仅点确定才校验非空。
可改进点（供方案参考）

体验与视觉短板

  • 校验滞后：空值要等点「确定」才提示，应在输入时实时校验。
  • 两个只读框：原始地址 + 预览本质重复，可合并或弱化原始地址。
  • 无语法高亮差异对比：仅高亮整段 host，未对比"改前→改后"。
  • 未提供浅色/护眼变体：长时间修源仍偏暗。
  • 极端 DPI 下偏挤，建议适当加大内边距与高度。

风格：毛玻璃背景 + 顶部蓝色高光描边，输入框为胶囊形，结果用圆角 chip。
  • 最"轻盈现代"，适合暗色主程序。
  • 主次按钮分明（确定=蓝色实心胶囊）。
  • 缺点：毛玻璃在 WinForms 需自绘，落地成本略高。
方案 C · 行内编辑 + 差异就地改 URL · 红绿变更对比

http://10.0.0.5:554/live/tv1.m3u8
192.168.1.100:8080→10.0.0.5:554
取消
应用
风格：整条 URL 当作可编辑行，仅 host:port 段高亮可改，path 锁定；下方红绿差异展示变更。
  • "所见即所得"，改哪看哪，误操作最低。
  • 差异对比直观，最适合批量修源。
  • 落地需自定义 URL 行编辑器（中等成本）。
