# IPTVLiveChecker
IPTV直播源检测工具 v1.0.1（正式版）
开发者：半步沧桑
反馈邮箱：xiaomiren0510@gmail.com

## 功能清单
- 批量检测 IPTV 直播源可用性（多线程、可调速）
- 支持 ffprobe / ffmpeg / MediaInfo 媒体解析
- 自动识别视频分辨率、音视频编码格式、帧率、码率
- 链接解析、搜索、频道分组管理
- 直播源批量生成、合并、导出 M3U / TXT（导出时支持频道清洗）
- IP 归属地查询、网络响应速度测速
- 预览窗功能：直接预览直播源画面
- 流媒体信息实时显示
- 一整套可切换主题（含玻璃拟态、极光、液态等质感）
- 直播源台标适配
- 内置自动更新（Updater）：联网检测新版本并一键升级
